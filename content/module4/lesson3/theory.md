# Урок 4.3 — Деплой модели: FastAPI-сервис

## Модель в ноутбуке — это не продукт

Вы обучили CatBoost, сохранили его в `best_model.pkl`. Отлично. Но что дальше? Бизнес не может «открыть ваш ноутбук» и нажать «Запустить». 

Модель должна жить в **веб-сервисе**, к которому обращаются другие системы. Например:
- CRM оператора отправляет данные клиента → получает вероятность оттока.
- Мобильное приложение менеджера показывает клиентов в зоне риска.
- Автоматический скрипт формирует список для ретеншн-кампании раз в сутки.

Это называется **деплой модели** (model deployment).

## Что такое API

**API** (Application Programming Interface) — это способ общения между программами. Одна программа делает HTTP-запрос, другая отвечает.

Пример запроса:

    POST http://localhost:8000/predict
    Content-Type: application/json

    {
      "стаж_месяцев": 12,
      "жалобы_12мес": 2,
      "просрочки_платежей_12мес": 1,
      ...
    }

Пример ответа:

    {
      "probability": 0.78,
      "will_churn": true
    }

Любая система, умеющая делать HTTP-запросы (Python, Go, JS, Java), сможет пользоваться вашей моделью. Не нужно ставить CatBoost на сервер клиента — достаточно отправить JSON.

## Почему FastAPI

**FastAPI** — самый популярный Python-фреймворк для ML-сервисов. Почему:

1. **Быстрый.** На уровне Node.js и Go.
2. **Автодокументация.** Генерирует Swagger UI и OpenAPI-схему автоматически.
3. **Валидация через Pydantic.** Если клиент пришлёт `стаж_месяцев = "abc"` вместо числа — FastAPI вернёт ошибку 400 сам.
4. **Асинхронность.** Работает с async/await.
5. **Pythonic.** Тот же синтаксис, что в sklearn.

## Как выглядит простой сервис

    from fastapi import FastAPI
    from pydantic import BaseModel
    import joblib

    app = FastAPI()
    model = joblib.load('best_model.pkl')

    class Client(BaseModel):
        стаж_месяцев: int
        жалобы_12мес: int
        # ... остальные признаки

    @app.post('/predict')
    def predict(client: Client):
        data = pd.DataFrame([client.dict()])
        prob = model.predict_proba(data)[0, 1]
        return {'probability': float(prob), 'will_churn': bool(prob > 0.5)}

Всё. 15 строк — и модель доступна по HTTP.

## Pydantic: валидация на входе

`BaseModel` — это класс, который описывает **схему** входных данных. FastAPI автоматически проверяет, что запрос соответствует схеме:

- Если `стаж_месяцев` не передан — ошибка 422.
- Если передан как строка `"12"` — ошибка 422 (не тот тип).
- Если число вне диапазона (например, отрицательное) — можно задать через `Field(ge=0)`.

Это защищает от мусора и делает API самодокументируемым.

## Обработка ошибок

Если клиент прислал битые данные или модель упала — клиент должен получить понятную ошибку, а не голый stack trace.

    from fastapi import HTTPException

    @app.post('/predict')
    def predict(client: Client):
        try:
            data = pd.DataFrame([client.dict()])
            prob = model.predict_proba(data)[0, 1]
            return {'probability': float(prob)}
        except Exception as e:
            raise HTTPException(status_code=500, detail=f"Ошибка модели: {str(e)}")

## Почему не просто Flask

Flask — тоже хороший фреймворк, но:
- Нет автоматической валидации (нужно ставить `marshmallow` или `pydantic`).
- Нет автодокументации (нужно ставить `flasgger`).
- Медленнее на нагрузке.

FastAPI даёт всё это из коробки. Для ML-сервисов — стандарт де-факто.

## Развёртывание в проде

В реальном проекте поверх FastAPI ставят **gunicorn** или **uvicorn** (ASGI-сервер), а сверху — **nginx** (reverse proxy) и **docker**. Но для курса достаточно:

    uvicorn main:app --host 0.0.0.0 --port 8000

Это запустит сервис на порту 8000. Любой клиент может обращаться к `http://localhost:8000/predict`.

## Российский контекст

В российском финтехе и телекоме типичная архитектура ML-сервиса:
- **FastAPI** — модель.
- **Docker** — изоляция.
- **Kubernetes** — масштабирование (10–100 реплик).
- **Redis** — кэш частых запросов.
- **Prometheus + Grafana** — мониторинг.

На собеседовании на позицию ML-инженера вопрос «как задеплоить модель?» — обязательный. Ответ «FastAPI + Docker» — правильный.

2. Эндпоинт принимает JSON с полями: `стаж_месяцев`, `жалобы_12мес`, `просрочки_платежей_12мес`, `ежемесячный_платёж_руб`.
3. Возвращает `{"probability": float, "will_churn": bool}`.
4. Протестируйте через `requests.post` прямо в этом же скрипте.

Подсказки:
- Модель `best_model.pkl` — CatBoost с категориальными фичами. Если ваш клиент присылает только 4 числовых поля — модель упадёт из-за отсутствия категорий. В задании проще **не загружать модель**, а имитировать предсказание: `probability = 0.5 + 0.1 * (жалобы - просрочки)`. Настоящий деплой вы сделаете в финальном проекте.
- Для реального теста запустите сервер в отдельном терминале через `uvicorn`, но в песочнице мы просто тестируем логику через `TestClient`.
